## 3. Bugs found and fixed during development

1. **Published-roster serialization crash:** `RosterOut.published_at` was
   typed `str` but held a `datetime`, so fetching a published roster
   failed. Fixed by typing it `datetime`.
2. **Dead fairness pass:** the first version only converted "surplus"
   workdays, but generation never assigns above the minimum, so the pass
   could never fire. Rewrote it as a coverage-preserving swap pass.
3. **Fairness ping-pong:** the swap pass took offs from employees who had
   just reached the minimum. Fixed by only swapping to employees holding
   surplus offs.
4. **Synchronized Ion Saturday blackouts misread as a bug:** with exactly
   3 staff for a 3-person daily requirement, the whole team is forced off
   together every Saturday. Kept as the deliberate understaffing demo and
   documented; certification-based backups cover it.
5. **Misleading weekend-fairness metric:** a cross-population weekend
   fairness score read 0.0 because weekday-only brands work zero weekends.
   Removed the metric; per-employee weekend days are reported instead.
6. **Missing `preferences_applied` in roster responses:** found by the
   frontend build; added to `RosterOut`.

## 5. Deployment honesty

No public deployment was performed and no deployment URL exists for this
project. The Docker Compose stack (PostgreSQL + backend + frontend) is
provided for self-hosting but was not executed end to end in this
environment. Local verification (API + tests + frontend build) is complete
as documented in §2.

## 6. Known limitations

- Auth is demo-grade (PBKDF2 + opaque bearer tokens; no SSO, no refresh
  rotation, no rate limiting).
- Notifications are in-app only; no email/SMS gateway.
- `create_all` still runs on backend startup for local development; the
  Alembic migration path is the deployment route.
- The demo seed's fairness score (0.6073) is measured across scheduled
  staff by design; the all-employee figure (0.2266) is also stored, because
  backup-pool staff who were not needed work 0 days.
